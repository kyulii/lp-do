# 화면 UI 기획 (Web)

## 1. 전체 컨셉: Vinyl LP Bar
*   할 일 하나하나를 **'트랙(Track)'**으로 삼고, 오늘 하루를 마무리하면 하나의 **'LP 앨범(Album)'**이 완성되는 형태의 투두리스트입니다.
*   디자인 무드: **모던 카페 (Modern Lounge)**
    *   배경색: 눈이 편안하고 따뜻한 베이지 (#f7f6f2) 및 오프화이트.
    *   포인트: 깔끔한 산세리프체(Helvetica 등)와 LP 턴테이블의 질감.

## 2. 화면 레이아웃 (Master-Detail 구조)
화면은 좌측의 **사이드바 영역(1/4 너비)**과 우측의 **메인 상세 영역(3/4 너비)**으로 분리되어 함께 표시됩니다.

### 2.1. 좌측 사이드바 구조 (나의 앨범 아카이브)
*   **역할:** 과거부터 오늘까지 쌓아온 나의 일별 LP 앨범(히스토리)들을 스크롤하며 찾아보는 **'서랍(Crate)'** 역할.
*   **UI 구성:**
    *   목록은 상단부터 '1일, 2일, 3일... 오늘' 순서의 **오름차순**으로 배치되어 세로로 길게 스크롤 됩니다.
    *   각 날짜의 항목은 **완벽한 정사각형(1:1 비율)** 형태의 앨범 케이스 디자인을 갖습니다.
    *   날짜나 진행 상황(Status) 같은 정보들은 앨범 자켓 자체에 인쇄된 디자인처럼 내부에 타이포그래피 처리됩니다.

### 2.2. 우측 메인 상세 영역 (턴테이블 & 트랙리스트)
*   **역할:** 사이드바에서 선택한 특정 날짜의 디테일한 할 일을 확인하고 조작하는 공간.
*   **UI 구성:**
    *   중앙에 커다랗고 매끄러운 **모던 턴테이블 디자인(LP 플레이어)**이 위치합니다.
    *   플레이어 옆에는 실제 앨범 자켓 뒷면에 적힌 **트랙리스트** 형태를 차용한 '할 일 목록(To-Do List)'이 나열됩니다.
    *   트랙 아래에는 새로운 할 일을 추가할 수 있는 버튼이 위치합니다.
