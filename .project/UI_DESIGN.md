# 화면 UI 기획 (Web)

## 1. 기본 용어 사전 (Terminology)
원활한 커뮤니케이션과 기획의 일관성을 위해 앱 내 주요 요소를 아래와 같이 지칭합니다.
*   **트랙 (Track):** 사용자가 수행해야 할 할 일(Task) 1건.
*   **LP (LP판):** 앨범 안에서 튀어나오거나 턴테이블에서 돌아가는 원형 레코드 시각 요소.
*   **앨범 (Album):** 하루 단위의 할 일 모음 (정사각형 카드 형태).
*   **아카이브 (Archive):** 한 달 단위의 앨범들이 모여있는 캘린더 전체 구역.
*   **턴테이블 (Turntable):** 선택한 앨범을 재생(확인)하는 우측 상세 보기 패널 전체.
*   **트랙리스트 (Tracklist):** 턴테이블 하단에 나열되는 상세 트랙(할 일) 목록.

## 2. 전체 컨셉: LP Collection & Player
*   할 일 하나하나를 '트랙'으로, 하루를 '앨범'으로, 한 달을 '아카이브'로 비유하는 LP 테마 투두리스트입니다.
*   디자인 무드: 따뜻한 베이지 계열의 배경(아카이브)과 대비되는 다크 모드(턴테이블)를 결합하여 모던하고 감각적인 느낌을 줍니다.

## 3. 화면 레이아웃 (Archive - Turntable 구조)
화면은 스크롤이 전혀 없는(100vh 고정) 레이아웃으로 구성되며, 좌측 **아카이브(3/4 너비)**와 우측 **턴테이블(1/4 너비)**로 분리됩니다.

### 3.1. 좌측 영역: 아카이브 (Archive)
*   **컨테이너 여백:** 아카이브 전체 영역은 사방에 넉넉한 패딩(Padding)을 주어 답답하지 않게 숨통이 트인 공간을 확보합니다.
*   **스크롤 없는 6줄 캘린더:** 화면 크기에 상관없이 7열 6행(총 42칸)의 그리드가 항상 브라우저 화면 안에 100% 들어오도록 반응형으로 설계됩니다.
*   **앨범 (정사각형 카드):** 
    *   그리드 내부의 각 날짜(앨범)는 **완벽한 정사각형(1:1 비율)**을 유지하며 셀 공간을 꽉 채웁니다.
    *   앨범과 앨범 사이의 간격(Gap)은 조밀하게 배치하여 캘린더의 응집력을 높입니다.
    *   앨범 안에는 날짜 숫자와 해당 날짜의 트랙(할 일)들이 요약되어 텍스트로 표시됩니다.

### 3.2. 우측 영역: 턴테이블 (Turntable)
*   **턴테이블 그래픽:** 상단에는 앨범을 재생 중인 것 같은 커다란 LP 플레이어 그래픽이 위치하며, 중앙 라벨에 선택된 날짜 정보가 표시됩니다.
*   **트랙리스트:** 하단에는 해당 날짜의 상세 트랙들이 목록 형태로 나열됩니다.
*   **입력 폼:** 트랙리스트 하단에 새로운 트랙을 추가할 수 있는 `[+ Add Track]` 버튼이 상시 노출됩니다.
