# 서비스 기능 및 UX 흐름 기획

## 1. 앨범 사이드바 인터랙션 (UX)
*   **마우스 오버 (Hover):** 좌측 사이드바의 정사각형 앨범 케이스에 마우스를 올리면, 케이스 안에 숨어있던 **블랙 레코드판이 우측으로 빼꼼** 튀어나옵니다. 앨범 자체가 살짝 떠오르며 그림자가 짙어집니다.
*   **앨범 선택 (Click):** 
    1. 클릭한 앨범은 '활성화' 상태가 되어 레코드판이 케이스 밖으로 절반가량 꺼내진 채로 고정됩니다.
    2. 클릭하는 순간, **우측의 메인 상세 영역(플레이어와 트랙리스트)**이 부드럽게 페이드 아웃 후, 새 날짜의 데이터로 페이드 인을 하며 전환됩니다. (화면 깜빡임 없는 전환)

## 2. 할 일 목록(트랙리스트) 인터랙션 (UX)
*   **트랙 추가:** `[+ 새 트랙 추가]` 버튼을 눌러 그날의 할 일을 작성합니다. (오늘 날짜의 앨범이 선택된 상태에서만 가능하도록 제한할 수 있습니다.)
*   **트랙 완료 처리:**
    1. 사용자가 트랙(할 일)을 클릭하면 텍스트에 **취소선**이 그어지며 완료 상태로 변경됩니다.
    2. 동시에 좌측 플레이어에 있는 **LP판이 빙글빙글 회전(Spin)**하기 시작합니다!
    3. (의미) '일을 완수했다'는 행동이 곧바로 '해당 트랙을 플레이한다'는 시각적 피드백으로 이어져 극강의 쾌감을 제공합니다.

## 3. 예외 및 엣지 케이스 (Edge Cases)
*   **빈 하루 (할 일이 없는 날):** 시스템이 자동으로 `[기록 없음]` 이라 적힌 회색빛의 심플한 앨범 커버를 생성합니다.
*   **하루의 시작:** 앱에 첫 접속 시 최하단(오름차순)에 위치한 **'오늘' 앨범이 기본으로 선택**되어 있어야 합니다.
