# 서비스 기능 및 UX 흐름 기획

## 1. 아카이브 앨범 인터랙션 (UX)
*   **LP 슬라이딩 & 스핀 (Hover):** 
    *   아카이브 내의 특정 앨범(하루)에 마우스를 올리면, 앨범 케이스 우측에서 숨어있던 **LP판이 앨범 너비의 절반(55%) 정도 튀어나오며 정중앙 부근에 위치**하도록 자연스럽게 슬라이딩됩니다.
    *   튀어나옴과 동시에 LP판은 실제 턴테이블 위에서 도는 것처럼 **끊임없이 빙글빙글 회전(Spin)**합니다.
    *   이 시각적 효과는 사용자가 마우스를 올리고 있는 동안 계속 유지되며, 마우스를 치우면 LP가 다시 앨범 속으로 부드럽게 들어갑니다.
*   **앨범 선택 (Click):** 
    *   앨범을 클릭하면 우측의 **턴테이블(상세 패널)** 영역이 클릭한 앨범의 데이터(날짜 및 트랙리스트)로 즉시 업데이트됩니다.
    *   선택된 앨범은 테두리가 굵어지거나 하이라이트 컬러로 표시되어, 현재 재생(활성화) 중인 앨범임을 명확히 인지시킵니다.

## 2. 턴테이블 동작 및 트랙 관리 (UX)
*   **트랙리스트 확인:** 클릭한 앨범의 상세 트랙(할 일)들을 우측에서 확인합니다.
*   **트랙 완료 처리:**
    *   사용자가 트랙 좌측의 체크박스를 클릭하여 완료하면, 해당 트랙 텍스트에 **취소선**이 그어지고 텍스트 색상이 회색으로 흐려져 완료 상태를 시각적으로 보여줍니다.
*   **상시 턴테이블 애니메이션:** 
    *   우측 상단에 위치한 커다란 턴테이블 그래픽은 앱을 사용하는 동안 10초 주기로 천천히 무한 회전하며 생동감을 더합니다.

## 3. 반응형 및 엣지 케이스 (Edge Cases)
*   **트랙이 없는 빈 앨범:** 할 일이 하나도 없는 날짜도 아카이브에는 빈 앨범 형태로 노출되어야 합니다.
*   **완벽한 반응형 비율 유지:** 브라우저의 가로/세로 창 크기를 조절하더라도 스크롤바가 절대 생기지 않아야 합니다. 아카이브 안의 모든 앨범들은 가용 공간 안에서 가장 큰 '완벽한 정사각형' 비율을 스스로 계산하여 유동적으로 축소/확대됩니다.
*   **오늘 날짜 기본 선택:** 사용자가 앱에 처음 접속하면 '오늘' 날짜의 앨범이 기본으로 선택되어 턴테이블에 플레이되고 있어야 합니다.
