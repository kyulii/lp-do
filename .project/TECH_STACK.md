# 기술 스택 (Tech Stack)

## 1. 프론트엔드 (Frontend) & 상태 관리
*   **프레임워크:** Next.js (App Router 기반)
    *   도입 목적: Vercel 배포에 가장 완벽하게 최적화된 프레임워크입니다. 투두리스트의 성격상 인터랙션이 많아 클라이언트 컴포넌트(`'use client'`) 위주로 코드가 짜이겠지만, 폴더 기반의 매우 편한 라우팅과 강력한 개발 환경을 제공합니다.
*   **언어:** TypeScript (코드의 안정성과 유지보수성을 위해 도입)
*   **상태 관리 (State Management):** Zustand
    *   도입 목적: 가볍고 직관적인 상태 관리 라이브러리. 좌측의 '아카이브(캘린더)' 컴포넌트와 우측의 '턴테이블(상세 패널)' 간에 **"현재 선택된 날짜와 트랙리스트 데이터"**를 복잡한 과정 없이 즉각적으로 동기화하기 위해 사용합니다.
*   **스타일링:** Vanilla CSS (모던 CSS 기능 활용, LP 회전 및 슬라이딩 등 디테일하고 매끄러운 CSS 애니메이션을 브라우저 부담 없이 직접 구현)

## 2. 백엔드 및 데이터베이스 (BaaS)
*   **BaaS (Backend as a Service):** Supabase
*   **특징:** 별도의 백엔드(서버) 코드를 작성하지 않습니다. 프론트엔드에서 클라우드 데이터베이스(PostgreSQL)에 직접 연결해 데이터를 읽고 쓰며, 사용자 인증(Auth) 기능까지 한 번에 안전하게 해결하는 서버리스(Serverless) 아키텍처입니다.

## 3. 배포 (Deployment)
*   **호스팅:** Vercel 
    *   도입 목적: Next.js를 만든 회사의 서비스이므로 궁합이 가장 좋습니다. GitHub에 코드를 올리기만 하면 복잡한 설정 없이 자동으로 무료 배포가 완료됩니다.
