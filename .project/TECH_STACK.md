# 기술 스택 (Tech Stack)

## 1. 프론트엔드 (Frontend) & UI
- **라이브러리:** React.js (컴포넌트 기반 아키텍처로 UI 재사용 및 애니메이션 처리 용이)
- **빌드 도구:** Vite (초고속 빌드 및 개발 환경 경험)
- **언어:** JavaScript 또는 TypeScript (안정성을 위해 TypeScript 권장)
- **스타일링:** Vanilla CSS (CSS Modules 또는 직접 작성하여 브라우저 부담을 최소화, 최고급 비주얼과 애니메이션 구현 목표)

## 2. 백엔드 및 데이터베이스 (Backend & DB)
- **BaaS (Backend as a Service):** Supabase
- **이유:** 친구분의 조언대로, 백엔드 서버를 직접 구축하지 않고도 빠르고 강력하게 DB(PostgreSQL 기반)와 인증 기능을 구현할 수 있는 최적의 도구입니다.

## 3. 배포 (Deployment)
- **호스팅:** Vercel (React 코드를 GitHub에 올리면 자동으로 빠르고 무료로 전 세계 서버에 배포해 줌)
