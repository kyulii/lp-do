# 전체 개발 기획 로드맵 (Development Roadmap)

이 문서는 프로젝트가 어떻게 진행될지 단계별로 요약하는 마일스톤입니다.

## Step 1: 기획 및 디자인 마침표 찍기
- [x] UI/UX 기획 및 용어 정리 (아카이브, 앨범, 턴테이블, 트랙 등)
- [x] 스크롤 없는 반응형 캘린더 및 슬라이딩/스핀 애니메이션 와이어프레임 확정
- [x] 데이터베이스(Supabase) 구조 및 기술 스택(Next.js, Zustand) 확정

## Step 2: 개발 환경 세팅
- [ ] Next.js (App Router) 기반의 프로젝트 생성 (`lp-do` 폴더 내)
- [ ] Zustand 등 상태 관리 및 필수 라이브러리 설치
- [ ] Supabase 프로젝트 생성 및 환경 변수 연동 세팅
- [ ] 화면 레이아웃 컴포넌트 뼈대 생성 (Archive, Turntable)

## Step 3: 프론트엔드 UI 및 애니메이션 개발
- [ ] 좌측 아카이브(캘린더) UI 구현 (스크롤 없이 6줄이 화면에 꽉 차는 정사각형 그리드)
- [ ] 우측 턴테이블 패널 및 트랙리스트 UI 구현 (다크 모드 베이스)
- [ ] 앨범에 마우스 호버 시 LP가 튀어나오고 회전하는 핵심 애니메이션 구현
- [ ] Zustand를 이용해 아카이브에서 날짜 클릭 시 우측 턴테이블 데이터 동기화

## Step 4: Supabase 데이터 연동
- [ ] Supabase 이메일 간편 로그인 UI 및 로직 구현
- [ ] 트랙(할 일) 추가 / 체크(완료) / 삭제 기능 DB 연동 작업
- [ ] 하루 단위 마감 및 Albums(아카이브용 통계/커버 정보) 테이블 업데이트 연동

## Step 5: 마무리 및 배포
- [ ] 사운드 이펙트(틱 소리 등)와 마이크로 애니메이션 최적화로 디테일 강화
- [ ] 반응형 깨짐 등 엣지 케이스 처리 및 전체 버그 테스트
- [ ] Vercel로 최종 배포하여 실제 접속 가능한 URL 획득!
